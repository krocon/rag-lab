# Password Security for Everyday Accounts

Most account takeovers do not involve clever hacking but reused or guessable passwords.

## Passphrases

Length matters more than complexity. A passphrase of four or five random, unrelated words is easier
to remember and harder to crack than a short password with symbols. Never build passwords from
personal facts such as birthdays or pet names, which attackers find on social media.

## Password managers

A password manager generates a unique random password for every site and fills it in
automatically, which also protects against phishing pages on look-alike domains. You only need to
remember one strong master passphrase. Keep an emergency kit with the recovery code in a safe
physical place, because a forgotten master passphrase usually cannot be reset.

## Two-factor authentication

Two-factor authentication (2FA) requires a second proof besides the password. Authenticator apps
that show six-digit time-based codes are much safer than SMS codes, which can be intercepted through
SIM swapping. Hardware security keys based on FIDO2 and passkeys resist phishing entirely. Store the
backup codes you receive during setup offline.

## After a data breach

If a service you use reports a breach, change the password there immediately and anywhere you
reused it. Check breach notification services for your email address, and watch for phishing emails
that refer to the breach to appear trustworthy.
